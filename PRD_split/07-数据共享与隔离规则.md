# 七、数据共享与隔离规则

> 来源：PRD V2.2 第七章
> 文档版本：V2.2 | 2026-06-04 | HeBen_Cat

## 7.1 共享的数据

| 数据类型 | 共享方向 | 说明 |
|---------|---------|------|
| 商品库 | 批发商 → 零售商 | 批发商录入的商品可共享给指定零售商，零售商发起进货请求后自动进入其数据库 |
| 商品单推荐 | 批发商 → 零售商 | 批发商在聊天中发送商品单，零售商可一键导入 |
| 补货建议 | 批发商 → 零售商 | 批发商可向零售商提交补货建议 |

## 7.2 隔离的数据

| 数据类型 | 隔离说明 |
|---------|---------|
| 销售数据 | 每个用户只能看到自己的销售记录 |
| 经营分析 | 每个用户只能看到自己的分析数据 |
| 进货数据 | 每个用户只能看到自己的进货记录 |
| 库存数据 | 每个用户只能看到自己的库存 |
| 利润/毛利 | 任何情况下不对其他角色开放 |
