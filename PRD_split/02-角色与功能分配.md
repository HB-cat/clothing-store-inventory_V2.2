# 二、角色与功能分配

> 来源：PRD V2.2 第二章
> 文档版本：V2.2 | 2026-06-04 | HeBen_Cat

## 2.1 零售商（功能完整度：100%）

- 商品管理（添加/编辑/删除，含属性组合库存）
- 分类管理（动态增删改、拖拽排序，sort_order持久化）
- 属性管理（属性组/属性值管理）
- 销售记账（点击记账 + 智能体快捷指令 + 新建账单模式，销售时必选买家，可选"散客"）
- 进货入库（三个来源：我的商品 / 新建并入库 / 批发商共享库）
- 账单查询（今日/本月/本年快捷查询，左滑退货，长按查看详情含进价毛利）
- 经营分析（今日快报、补货建议、滞销提醒、热销TOP8、近7天趋势、订单高峰、客户画像）
- 库存查看（实时库存，按属性组合展示）
- 商品导入（从批发商共享库中导入，批零交易自动联动）
- 聊天（与买家聊天 + 与批发商聊天，接收商品单推荐）
- 数据管理（导出/恢复/初始化，需密码验证）
- 运行状态提示（顶部居中，联网跑马灯，断网静态提示）
- 音效反馈（可开关）
- 可拖拽菜单（我的页面模块排序）
- 智能体（全局浮窗、自然语言、主动建议、可全关）

## 2.2 批发商（功能完整度：100%）

与零售商完全一致，额外增加：
- **商品共享**：将商品共享给指定零售商，发送商品单推荐（聊天中一键发送多商品）。
- **批零交易确认**：零售商发起进货请求后确认售出，自动扣减自身库存并增加零售商库存。

## 2.3 买家（功能完整度：10%）

- 搜索并关注零售商（搜索全部，关注后才可互动）
- 浏览关注零售商的商品列表（仅看售价，不进价不展示库存）
- 预约到店（2小时时段，查看/取消预约）
- 与商家聊天（文本、图片、商品卡片，可发送商品卡片）
- 查看历史订单（数据来源于卖家记账时关联买家）
- 填写个人信息（年龄、身高、体重、三围、穿衣风格偏好，供卖家客户画像）
- 离线时：直接停服并显示歉意提示

## 2.4 管理员（后门功能）

- 用户管理（查看用户列表、禁用/启用账号）
- 数据查看（各用户商品数量、订单数量，不查看金额）
- 系统配置（服务器参数、清理过期数据）
