# 十、技术方案

> 来源：PRD V2.2 第十章
> 文档版本：V2.2 | 2026-06-04 | HeBen_Cat

| 层级 | 技术选型 |
|------|----------|
| 客户端 | Android 原生 (Java) |
| 最低 SDK | Android 8.0 (API 26) |
| UI 框架 | XML 布局 + 自定义 Drawable |
| 本地数据库 | Room (SQLite)，加密使用 SQLCipher |
| 图表库 | MPAndroidChart v3.1.0（稳定可靠） |
| 后端 | Spring Boot 3.2.0 + MyBatis-Plus 3.5.7 |
| 数据库 | MySQL 8.0 |
| 网络通信 | Retrofit 2.9.0 + Gson |
| 认证 | Token (UUID)，30天有效期 |
| 数据同步 | 云端优先 + 本地缓存 + 离线队列 |
| 智能体规则引擎 | 本地正则匹配 + 关键词提取（≤200ms） |
| 智能体大模型 | DeepSeek API，经后端 `/agent/parse` 代理转发 |
| 音效 | MediaPlayer + res/raw |
| 异常捕获 | 全局 CrashHandler |
