## 3.1 浮窗形态

- 默认状态：屏幕边缘吸附的半透明圆形浮窗（直径48dp），显示智能体图标。
- 交互规则：
  - 用户点击浮窗 → 展开为输入面板（宽280dp，含文本输入框、语音按钮、发送按钮）。
  - 8秒未操作 → 浮窗自动贴边并半透明隐藏（不遮挡内容）。
  - 在任何页面均可唤醒，浮窗层级最高（`TYPE_APPLICATION_OVERLAY`）。
  - 可拖拽移动位置，登录页/注册页不显示。
- 输入方式：默认文本指令模式；含敏感词（如"把[商品]发给[人]"）时自动切换为商品卡片发送模式。
- 语音按钮：先做UI占位，后续接入。

## 3.2 智能体能力

### 3.2.1 意图解析

采用**本地规则引擎优先 + DeepSeek大模型兜底**的双模架构：
- 规则引擎（正则匹配 + 关键词提取）：覆盖高频确定指令，响应 ≤200ms，无需网络。
- 规则引擎未匹配 → 请求后端 `/agent/parse` 代理转发至 DeepSeek API，返回结构化结果。
- 断网时：规则引擎正常执行，匹配不到则提示"换个说法试试"。
- 所有指令解析结果均以**确认弹窗**展示，用户手动确认后才执行。

支持指令类型：
- 销售记账："卖了红色连衣裙2件90元"
- 账单操作："新建一个账单，加入T恤3件"、"提交第一个账单"
- 查询："本月销售额多少？"
- 退货："退掉刚才那笔连衣裙"
- 预约管理："接受李小姐的预约"、"拒绝王先生的预约，理由今天休息"
- 商品/分类管理："添加分类'鞋类'"
- 页面跳转："打开经营分析"
- 系统设置："关闭声音"、"把商品管理菜单移到第一位"
- 发商品卡片："把连衣裙发给李小姐"

### 3.2.2 主动建议

- 学习用户行为（高频操作、常用商品、常用时段、页面停留时长），在适当时机主动推荐操作。
- 示例：
  - 进入首页时，若有未提交账单 → 提示"您有3个未提交账单，需要提交吗？"
  - 每天习惯查销售的时间前10分钟 → "该查看今日销售了"
  - 库存低于预警 → "连衣裙库存不足，需要进货吗？"
- 展示形式：浮窗轻提示（3秒自动消失），带"好的""稍后"按钮。
- 用户可在"程序设置 → 通知管理"中按类型独立开关，也可关闭全部主动建议。

### 3.2.3 学习机制

| 学习内容 | 存储位置 | 用途 |
|---------|----------|------|
| 操作频次 | 本地Room | 主动建议排序、指令优先级 |
| 常用商品TOP10 | 本地+云端 | 指令解析时优先匹配 |
| 常用价格区间 | 本地 | 自动填写售价 |
| 页面停留时长 | 本地 | 判断用户是否卡顿，主动帮助 |

### 3.2.4 安全限制

- 敏感操作（初始化系统、清除所有数据、修改密码）智能体仅协助填写，最终需用户手动确认并输入密码。
- 智能体不执行任何涉及资金直接转移或修改密码的操作。
- 密码不通过语音采集，必须手动输入。
