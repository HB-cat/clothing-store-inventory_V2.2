# 六、注册与安全

> 来源：PRD V2.2 第六章
> 文档版本：V2.2 | 2026-06-04 | HeBen_Cat

## 6.1 注册流程（两步）

**Step 1：选择角色**
- 零售商 / 批发商 / 买家 三选一（RadioButton或卡片选择），选后不可更改。
- 角色不同，Step 2展示的字段不同。

**Step 2：填写信息**

| 字段 | 说明 |
|------|------|
| 用户名 | 系统自动生成唯一ID码并实时展示，格式：`角色_5位随机字母数字`（如 `ret_Ab3Xy`），用户不可编辑 |
| 密码 | 用户自设，8-12位，字母+数字组合。同时用于登录和敏感操作二次验证 |
| 店铺名称 | 零售商/批发商必填，买家不显示此字段 |
| 昵称 | 买家必填，零售商/批发商不显示此字段 |

- 注册成功后跳转到登录页。
- 买家首次登录时弹窗提示"去完善个人信息"，提供"立即完善"和"稍后"按钮。

## 6.2 登录

- 输入用户名（ID码）和密码，可选择"记住密码"（存储用户名+密码到本地加密SharedPreferences）。
- Token认证，有效期30天。

## 6.3 密码使用场景

- 登录验证
- 初始化系统
- 清除所有数据
- 修改密码
- 智能体执行敏感操作时（如"重置系统"），弹窗提示"请输入密码"，转手动输入，不语音采集
