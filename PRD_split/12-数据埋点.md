# 十二、数据埋点（建议）

> 来源：PRD V2.2 第十二章
> 文档版本：V2.2 | 2026-06-04 | HeBen_Cat

| 事件 | 属性 |
|------|------|
| 智能体唤起 | 唤起方式（点击/语音/主动建议） |
| 指令解析结果 | 成功/失败，指令类型，响应耗时，解析方式（规则引擎/大模型） |
| 主动建议点击 | 建议内容，用户点击"好的"或"稍后" |
| 记账操作 | 来源（手动/智能体快捷指令/新建账单），是否关联买家 |
| 进货操作 | 来源（我的商品/新建并入库/批发商共享库） |
| 预约处理 | 卖家确认/拒绝/标记毁约，是否通过智能体 |
