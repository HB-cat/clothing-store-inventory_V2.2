# 十一、非功能需求

> 来源：PRD V2.2 第十一章
> 文档版本：V2.2 | 2026-06-04 | HeBen_Cat

## 11.1 性能

- 浮窗滑动帧率 ≥ 55fps。
- 智能体语音转文字延迟 ≤ 1.5s（离线语音，后续接入）。
- 本地规则引擎匹配 ≤ 200ms。
- 列表滑动流畅，图片加载使用缓存。

## 11.2 兼容性

- Android 8.0 ~ 14，悬浮窗权限需动态申请，拒绝后降级为不显示浮窗但保留语音输入入口。
- 后端接口支持跨域，提供标准 RESTful API。
- 买家端离线时：直接停服，显示歉意提示。

## 11.3 数据安全

- 密码使用 BCrypt 哈希存储。
- 本地数据库加密（SQLCipher）。
- 网络传输 HTTPS + Token，Token 有效期30天。
- DeepSeek API Key 仅存储在后端服务器，客户端不持有。

## 11.4 离线可用

- 首次登录同步必要数据（商品库、分类、属性）。
- 断网时，卖家端所有功能（包括智能体本地规则引擎指令）均可正常使用。
- 断网时智能体大模型兜底不可用，规则引擎匹配不到则提示"换个说法试试"。
- 联网后自动同步离线期间产生的数据，冲突策略以后端时间戳为准。
