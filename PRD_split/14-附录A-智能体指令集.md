# 附录A：智能体完整指令集（供开发）

> 来源：PRD V2.2 附录A
> 文档版本：V2.2 | 2026-06-04 | HeBen_Cat

本地规则引擎需支持以下示例（正则匹配 + 关键词提取）。规则引擎无法匹配的指令将自动转发 DeepSeek 解析。

| 意图 | 示例 | 提取关键信息 |
|------|------|-------------|
| 销售记账 | "卖了2件红色M码连衣裙，每件90元" | 商品名（模糊匹配），数量，单价，属性组合（可选） |
| 新建账单 | "新建一个账单，加入T恤3件" | 商品名，数量 |
| 提交账单 | "提交第一个账单" | 账单索引 |
| 查询销售 | "本月销售额"、"今天毛利多少" | 时间范围，指标类型 |
| 退货 | "退掉刚才那笔连衣裙" | 商品名（取最近未退货的销售记录） |
| 预约确认 | "接受李小姐的预约" | 买家昵称或预约ID |
| 预约拒绝 | "拒绝王先生的预约，理由今天休息" | 买家昵称，拒绝理由 |
| 打开页面 | "打开经营分析"、"进入商品管理" | 页面名称（预定义映射表） |
| 添加分类 | "添加分类'鞋类'" | 分类名称 |
| 删除分类 | "删除'上衣'分类" | 分类名称 |
| 添加商品 | "添加商品'牛仔裤'，进价80，售价150" | 商品名，进价，售价 |
| 进货入库 | "进货牛仔裤10条，进价70元" | 商品名，数量，进价 |
| 库存查询 | "有哪些库存不足的商品？" | 阈值（默认≤5） |
| 模块排序 | "把商品管理移到第一位" | 模块名，目标位置 |
| 系统设置 | "关闭声音"、"打开通知" | 设置项，状态 |
| 发商品卡片 | "把连衣裙发给李小姐" | 商品名，接收方 |
